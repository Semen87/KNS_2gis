# Справочник КНС — PWA

Готовый автономный справочник для телефона и компьютера.

## Запуск

Для офлайн-режима и установки как приложения разместите папку на обычном веб-сервере (например, GitHub Pages, Netlify или внутреннем сервере) и откройте `index.html` через `https://`.

При прямом открытии файла в браузере (`file:///`) просмотр списка работает, но установка и service worker будут недоступны — это ограничение браузеров.

## Данные

Данные лежат в `kns_data_export.js`. Файл должен экспортировать массив:

```js
export const knsData = [
  {
    number: "КНС 124",
    address: "Кудайбердыулы, возле д. 4",
    district: "Алматы",
    coordinates: "51.162718, 71.478789",
    twoGisUrl: "https://2gis.kz/search/51.162718,71.478789",
    pumps: "2 × Zenit",
    notes: ""
  }
];
```

Поле `fields` можно использовать для любых остальных столбцов Excel:

```js
fields: { "ЧРП": "Есть", "Производительность": "120 м³/ч" }
```

В текущем комплекте сохранён пустой массив, потому что последний Excel и исходный экспорт не были переданы в эту рабочую среду. Замените только содержимое массива на экспорт из последнего Excel — интерфейс адаптируется автоматически.
